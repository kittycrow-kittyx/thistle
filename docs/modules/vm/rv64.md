# vm/rv64

`Rv64` adapts hosted processes to the canonical native RV64 instruction core. It services Linux ABI requests with the live `Sys` VFS, streams and credentials, coordinates guest harts, and flushes shared file mappings. It contains no second instruction interpreter. Hosted file reservations use `thistleMapHostFile` and `thistleUnmapHostFile` so instruction access checks use the same address-space tables.

Every guest uses `Kern.canonical.memory` and its allocated leader hart. The
adapter does not initialise another kernel or copy credentials back from a
private guest kernel. Native process reaping releases guest frames.

Host syscall buffers use `thistleGuestAccess`. The adapter no longer interprets
segment, heap, stack or mapping permissions. Invalid guest buffers return the
canonical EFAULT result. Section validation belongs to `thistleLoadThx`; the
host retains section names only for diagnostics.
